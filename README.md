# Package Template

## Setup

* `nvm use && pnpm install`
* Optional: Install and setup the [github cli](https://cli.github.com/) if you want to take advantage of the optional `pnpm pr` command.

## What is this?

Use this template whenever creating a new package.

Read the short [guide](https://helloextend.atlassian.net/wiki/spaces/ENG/pages/1469087920/Creating+and+Publishing+Packages) to learn how to create and publish your package.
